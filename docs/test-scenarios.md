# Тестовые сценарии (E2E)

Предусловие: `docker compose up --build` на чистой БД (`docker compose down -v` для сброса),
открыть http://localhost:3000. Вход — кнопкой с нужной учётной записью (пароль `demo`).

| # | Учётка | Шаги | Ожидаемый результат |
|---|---|---|---|
| 1 | `romashka` | Получить кредит → «Пополнение оборотных средств» → 2 000 000 ₽, 24 мес. → согласие → Отправить в банк | `APPROVED`, скор 710, 2 000 000 ₽ / 24 мес. / 22.5 %, платёж ≈ 104 251 ₽; факторы: +80, +60, +70 |
| 1a | `romashka` | продолжение п.1: Принять предложение → отметить согласие → Подписать | `SIGNING` → `ISSUED`, график платежей, история из 7 событий |
| 2 | `vasilek` | «Текущие расходы», 1 000 000 ₽, 12 мес. → Отправить | `REJECTED`, «Недостаточная скоринговая оценка», факторы: просрочки, налоги, нагрузка |
| 3 | `lyutik` | «Текущие расходы», любые параметры → Отправить | `REJECTED`, «Компания не действует по данным ЕГРЮЛ» |
| 4 | `petrov` | «Текущие расходы», 300 000 ₽, 12 мес. → Отправить | `COUNTER_OFFER`: 180 000 ₽, 25.5 %; показана запрошенная сумма для сравнения |
| 5 | `romashka` | «Покупка оборудования», 15 000 000 ₽, 60 мес. → Отправить | `UNDERWRITING`, «Сумма от 10 млн ₽ — заявку рассмотрит кредитный специалист» |
| 5a | `underwriter` | Очередь → «Требуют решения» → заявка из п.5 → «Запросить уточнения», комментарий → Принять решение | `INFO_REQUESTED`; заявка во вкладке «Ждут клиента» |
| 5b | `romashka` | Открыть заявку → видно «Банк просит: …» → сумма 9 000 000 → Отправить повторно | `APPROVED`, 9 000 000 ₽ / 19 % |
| 5c | `underwriter` | Вариант п.5a: «Контрпредложение», 12 000 000 ₽, 20.5 % | `COUNTER_OFFER`; клиент видит условия и «Решение принял кредитный специалист» |
| 5d | `underwriter` | Вариант п.5a: «Отказать» без комментария | Ошибка «укажите комментарий для клиента» (422) |
| 6 | любой клиент | Повторно отправить заявку в статусе `REJECTED` через API | `409 Conflict` |
| 7 | `vasilek` | `GET /applications/{id}` заявки «Ромашки» с токеном «Василька» | `404` — чужие заявки недоступны |
| 8 | `romashka` | `POST /underwriter-decision` с токеном клиента | `403` |
| 9 | — | Остановить моки (`docker compose stop mocks`), подать заявку как `romashka` | `UNDERWRITING` с комментарием «Источник «БКИ» недоступен…»; после `docker compose start mocks` всё работает |

Автотесты (сценарии 1–9 через HTTP API, моки подменяются теми же данными): `cd backend && uv run pytest`.
